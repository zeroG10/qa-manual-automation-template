# Shared Checklists

Checklists that apply to **both web and mobile** — typically cross-cutting concerns:

- Accessibility (a11y) — WCAG, screen readers, contrast
- Security — input validation, auth, session handling, sensitive data
- Performance — load times, memory, network usage
- Localization & i18n — language, RTL, date/time formats
- Analytics — event tracking parity across platforms

Platform-specific checklists go under `../web/` or `../mobile/{ios,android,cross-platform}/`.
